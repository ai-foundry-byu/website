# Landing page UI kit

The hi-fi landing page: canvas direction 4b (white-dominant, royal accents, stamped nameplate, cast stack hero) on wireframe structure 1b. Composes the system components (NavBar, Button, Eyebrow, SectionHeader, Card, ValueRow, NameCarousel, Footer). All copy verbatim from `ai-foundry-byu/website` `src/lib/content.ts`.

Interactive: values expand on click, shipped-at strip auto-scrolls, sticky nav, in-page anchors.
